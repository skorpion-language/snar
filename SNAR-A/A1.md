# SNAR-A1

## Skorpion Norms And Rules, A generation. Standard A1

This standard applies to Skorpion Project Configuration files with the `*.spc` extension.

---

## 1. Lexis

The SPC lexis is formed by the following characters:

| Character | Name |
|-----------|------|
| `[` | LBracket |
| `]` | RBracket |
| `"` | Quote |
| `'` | Apos |
| `\` | Backslash |
| `.` | Dot |
| `<` | Lt |
| `>` | Gt |
| `-` | Minus |
| `,` | Comma |

The SPC lexer recognizes values of the following types: **String**, **Int**, **Float**, **Bool**, **Array**, and **Ident**.

### 1.1. String

A **String** value is an arbitrary sequence of ASCII characters. Length and permitted characters are further constrained by the specific parameter in which the value is used.

A String value is enclosed in a pair of:
- `"` (Quote) — on both sides, or
- `'` (Apos) — on both sides.

### 1.2. Int

An **Int** value consists only of digits `0–9` and, optionally, a `-` (Minus) character before the first digit.

### 1.3. Float

A **Float** value consists of digits `0–9`, a `.` (Dot) character separating the integer and fractional parts, and, optionally, a `-` (Minus) character before the first digit.

### 1.4. Bool

A **Bool** value takes exactly one of two values: `true` or `false`. The Bool type has no other values.

### 1.5. Array

An **Array** value is an ordered list of values of other types, enclosed between `<` (Lt) and `>` (Gt).

- An Ident **cannot** be an Array value.
- A `,` (Comma) is required between adjacent Array elements.
- A `,` (Comma) after the last element is optional.

### 1.6. Ident

An **Ident** value is written without brackets or quotes, consists only of the characters `A–Z`, `a–z`, and **contains no digits**.

---

## 2. Syntax

### 2.1. Parameter

A configuration parameter is written according to the pattern:

```
Param[Value]
```

where:
- `Param` — an identifier (Ident),
- `[` — an opening square bracket (LBracket),
- `Value` — a value of one of the permitted types,
- `]` — a closing square bracket (RBracket).

---

## 3. Semantics

### 3.1. Parameter

- `Param` acts as a **key**: it specifies the name of the configuration parameter.
- `Value` acts as a **value**: it contains the value required for the parameter with that name.

---

## 4. manifest.spc

`manifest.spc` is the Skorpion project configuration file. The standard defines 10 reserved parameters:

| Parameter | Type | Purpose |
|-----------|------|---------|
| `name` | String | Project name |
| `version` | String | Project version |
| `main` | String | Path to the main file |
| `target` | Array of String | Platform or platforms for the build |
| `env` | String | Environment variables applied during the build of this project (not applied to the built binary files) |
| `execute` | String | Arguments applied to the command during the project build |
| `buildOutName` | String | Name of the build output file |
| `buildOutPath` | String | Path to the build output file |
| `testOutName` | String | Name of the test build output file |
| `testOutPath` | String | Path to the test build output file |
