# SNAR-A0

## Skorpion Norms And Rules — Generation A — Standard A0

This standard is the table of contents for the SNAR-A generation.

---

## 1. General Provisions

### 1.1. Rule of Scope

The SNAR-A generation includes the following standards:

| Standard Name | Description | Link |
|---------------|-------------|------|
| SNAR-A0 | This file, table of contents | [`SNAR-A/A0.md`](../SNAR-A/A0.md) |
| SNAR-A1 | Description of the rules of vocabulary, syntax and semantics of the configuration language of the SPC (Skorpion Project Configuration) | [`SNAR-A/A1.md`](../SNAR-A/A1.md) |
| SNAR-A2 | Describes the vocabulary of the Skorpion language | [`SNAR-A/A2.md`](../SNAR-A/A2.md) |
| SNAR-A3 | Describes the syntax of the Skorpion language | [`SNAR-A/A3.md`](../SNAR-A/A3.md) |
| SNAR-A4 | Describes the semantics of the Skorpion language | [`SNAR-A/A4.md`](../SNAR-A/A4.md) |
| SNAR-A5 | Describes the `.sklib` library format and the rules for writing, reading, locating, and resolving Skorpion libraries | [`SNAR-A/A5.md`](../SNAR-A/A5.md) |
| SNAR-A6 | Describes the diagnostic codes emitted by a conforming implementation of the Skorpion compiler | [`SNAR-A/A6.md`](../SNAR-A/A6.md) |

### 1.2. Relationship Between Standards

The standards in the SNAR-A generation are organized as follows:

- **SNAR-A1** defines the SPC configuration language. It is independent of A2–A4 in its vocabulary, but its consumers (the `build`, `build-lib`, and related commands) rely on the Skorpion language defined in A2–A4.
- **SNAR-A2** defines the vocabulary. It depends on nothing else in the generation.
- **SNAR-A3** defines the syntax. It depends on **SNAR-A2** for its token types.
- **SNAR-A4** defines the semantics. It depends on **SNAR-A3** for its syntactic forms.
- **SNAR-A5** defines the `.sklib` library format. It depends on **SNAR-A2** through **SNAR-A4** for the meaning of the AST nodes it stores.
- **SNAR-A6** defines the diagnostic codes. It references **SNAR-A1** through **SNAR-A5** for the conditions each code corresponds to.
